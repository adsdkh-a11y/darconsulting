# VIVIA — Languages

Supported: English (reference), Italiano, Français, Español, Deutsch, العربية (RTL).

- Dictionaries: `vivia/src/lib/i18n/*.ts`, flat keys. `en.ts` is the source of truth; a test (`tests/i18n.test.ts`) fails if any language misses a key or changes a `{placeholder}`.
- IT was written first and is the most polished. **FR, ES, DE and AR were machine-assisted** and have not been reviewed by native speakers or by clinicians. Medical vocabulary (IBD: MICI / EII / CED / مرض التهاب الأمعاء; stoma/ostomía/Stoma/فغر) must be checked before launch.
- Not translated by design: the offline rules provider (log parsing, templated doctor questions) understands EN, IT and FR only; other languages fall back to English there. Glossary explanations are EN/IT only.
- Arabic uses `dir="rtl"`. Verify layout on a real device (icons, charts, bottom navigation, numbers).
- Review workflow: export a language with `node -e` or open its file, have a native speaker mark changes in a pull request, keep tone neutral (no diagnosis, no promises), and keep "VIVIA" untranslated.
