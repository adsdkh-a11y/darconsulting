# VIVIA logo files (working name)

- `vivia-icon.svg` / `vivia-icon-1024.png` — app icon (ribbon on dark violet square). Also used as `/icon.svg`.
- `vivia-mark.svg` / `vivia-mark-1024.png` — ribbon mark only, transparent background.
- `vivia-logo-dark.svg` / `.png` — full lockup for **dark** backgrounds (transparent).
- `vivia-logo-light.svg` / `.png` — full lockup for **light** backgrounds (transparent).

Wordmark text is outlined (Manrope ExtraBold, tracking 0.06 em), so the SVGs need no font. Colours: violet gradient `#C9B6FF → #7A52E0` (dark) or `#8A63F0 → #5B2FB8` (light); text `#F3F1FA` / `#120D22`.
"VIVIA" is a working name: trademark, domain and app-store availability have **not** been checked. The ribbon is a generic awareness symbol; a designer should finalise the mark before registration.
